# Tournée

Web app (PWA) pour iPhone qui optimise l'ordre d'une tournée de livraison au départ du dépôt.

- Géocodage : Géoplateforme IGN (base adresse nationale)
- Temps de trajet : OSRM (OpenStreetMap)
- Optimisation : plus proche voisin multi-départs + 2-opt + or-opt
- Données stockées uniquement sur le téléphone (localStorage)

Installation : ouvrir l'URL GitHub Pages dans Safari, puis Partager > Sur l'écran d'accueil.
